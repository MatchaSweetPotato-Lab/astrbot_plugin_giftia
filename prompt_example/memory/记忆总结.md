判断依据：new_messages 是本批待处理的聊天，不代表每条消息都包含新事实。可用媒体转述以 [描述:...] 紧随媒体标识嵌入正文，较长或重复的转述放在 media_content 中，按 media_id 对应。message 保留 source_id、user_id、nickname 和完整时间，reply_to（如有）是被回复者账号；结合正文中的 @ 识别互动对象。撤回消息、操作日志和指令已过滤，引用正文不作为直接发言。对象或含义不明确时不记录。

保存范围：
- 不记录画像信息：成员的头像外观、头像更换本身、好感度数值及其构成或增减、当前互动态度或关系状态、称呼和外号映射等，已有专门的画像模块维护并按需注入后续提示词。不要因这些字段再次被提及或发生变化而另建事实记忆。
- 不记录旧事复述：回忆、转述、重复说明或确认已知内容，没有新增信息时跳过。也不把再次谈起的时间当成原事件重新发生的时间。
- 不记录无后续用途的聊天：普通知识或百科解释、例行问候、礼貌感谢、简单附和、重复玩笑，以及没有后续影响的日常流水账均跳过。“我知道了”“我会记住”“聊得很开心”本身不构成具体约定或新的关系事实。
- 保留实际新增的信息：有用的个人背景、明确偏好、群内特定用法，或本批明确发生的纠正、补充、偏好变化、新约定及其履行或取消。只记录新增或变化部分及必要背景，不展开重写被复述的旧内容。用户本批新披露的有用过往经历也可记录，不能仅因使用过去时就判断为重复。

信息归属：群友的直接陈述可证明他本批提供的信息。你的发言可证明你本次新作出的具体承诺或已实际发生的行动，不能单独证明群友的过往经历、偏好、词义解释或态度。不要把你的推测、联想或普通回应转写成群友事实或新的关系进展。

associated_user_ids：事实涉及的群友完整账号列表，包含所有实际参与群友，不包含自身id。

importance：仅对通过上述筛选的事实输出 1~10 的整数，按其对后续互动的影响评分：1~3 为后续用途较有限的具体事实；4~6 为明确偏好或有用背景；7~8 为重要约定或长期适用的重要信息；9~10 为对互动有关键影响的明确底线或重大事实，谨慎使用。未通过筛选的内容直接跳过，不得通过赋低分保留下来。不因消息长度、情绪强烈或重复表达而提高分数，重要度不表示事实可信度或新旧程度。

evidence：证据数组，同一条记忆可引用多条消息，每条消息占一项，每项只填写一个 source_id，同一条消息只引用一次。

occurred_at：记录实际事件时间。相对时间参照消息日期转换为带时区的 ISO 时间，无法确定则留空。明确的约定及截止时间在正文中写清。
